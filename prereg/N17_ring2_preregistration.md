# 第 2 环预注册：签名在测什么（代理分解）——2026-10-15 写定，结果出来后不改

## 问题
已发表 HCC 细胞死亡签名（A 组）和 8 个机制基因集（B 组）的风险评分，有多少是增殖 / 基质 / 免疫 / OXPHOS 的代理？
调整这些代理后剩下的预后信号，是否比同尺寸随机签名多？

## 对象
- A 组：N12 语料中有完整系数、≥2 个基因落在三队列共同基因内的已发表签名；权重 = 原文系数 × TCGA 基因 sd（同第 3 环 A 组主分析）。
- B 组：8 个机制基因集，在 TCGA 上走模板流程 fitsig（单因素 Cox P<0.05 → LASSO-Cox）。
- 随机对照（同第 3 环预注册主分析口径 fitsig_k）：A 组每个签名 25 个、B 组每个集合 200 个同尺寸随机基因集（抽自 U），在 TCGA 上走 fitsig。

## 代理（沿用 N16 已签收的协变量定义）
增殖 = HALLMARK E2F ∪ G2M 的平均 z；OXPHOS = HALLMARK OXPHOS 平均 z；ESTIMATE Stromal / Immune（每队列各自计算）；分期 I–II / III–IV；年龄；性别。

## 指标（每个签名 × 每个队列 TCGA / GSE14520 / LIRI-JP）
1. 评分与各代理的 Spearman ρ。
2. 代理解释方差：lm(评分 ~ 增殖 + Stromal + Immune + OXPHOS) 的 R²。
3. 残余预后信号（只在两个外部队列）：Cox 嵌套似然比检验，基础模型 = 分期 + 增殖 + Stromal + Immune + 年龄 + 性别，对比基础模型 + 评分；另报每 SD 的未调整 HR 与调整 HR。

## 检验与报告（全部是有名字的标准方法）
- R²：真实 vs 随机，每队列 Mann–Whitney U 检验（双侧）；每个签名另报 Phipson–Smyth 经验 P。
- 残余信号：LRT P<0.05 视为该队列残余阳性；"两个外部队列都阳性"的比例，真实 vs 随机，Fisher 精确检验（双侧）；随机组阳性率另报 Clopper–Pearson 95% CI。
- 敏感性：基础模型再加 OXPHOS，重做第 3 项。
- 本环是描述 / 解释环，不设去留门槛；每项单独报告。
- 种子：A 组 5e6 + 1e3·签名序号 + rep；B 组 6e6 + 1e3·集合序号 + rep。
